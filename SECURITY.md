# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🔒 Reporting a Vulnerability

If you discover a client-side vulnerability (such as XSS, sensitive token leakage, or insecure origin policy):

1. **Do not disclose the issue publicly.**
2. Send an email to:
   - **Email:** `sufi11729@gmail.com`
   - **Subject:** `[SECURITY] PixCut Frontend Vulnerability Report`

We strive to respond within **24 hours** and release fixes promptly.
